# 去 AI 模板感与“真人手搓”工科学术规范（硬性约束）

以下六项是制作和修改学术答辩、组会汇报、项目评审 PPT 的硬性约束，均适用于最终上屏稿。讲稿、备注和原文核查记录可保留精确的原文定位。

## 1. 章节眉题与页内编号

- 有眉题的页面全篇采用同一体例。默认写成“一级章名 ｜ 本页独立中文主题”，右侧用 6–12 字的完整主题短语，例如“研究内容 ｜ 条件增益的估计方法”。不挂二级及以下阿拉伯数字编号。“文献综述 ｜ 2.1–2.3”不能说明这页讲什么。
- 确需保留二级编号时，每页至多一个，仍须配完整主题。按全篇页序比较章、节数值，严格递增，不回退、不堆叠。禁止在一行并排多个二级、三级节号、数字区间或括号编号。写全“研究可行性分析”“统计检验”等术语，放不下时重写整条眉题。
- 正文的并列项用无序号加粗短语，或从 1 开始在本页编号。源文档的“2.7 / 2.8 / 2.9”留在原文映射记录。

## 2. 可见底注与文献引证

- 正片和附录的可见文字均禁用节号符 `§`、自引报告节号、内部文件名及对账签。把“见开题报告 §3.3”或“见补充材料 PDF 第 59 页”的定位移到备注或核查记录。
- 本页没有对应文献列表时，正文和底注禁用孤立数字引文，如“HERBench [46]”。直接写可识别的作者或数据集，加年份或会议，例如“Liu 等，TACL 2024”。附录参考文献序号写成 `[1]` 至 `[9]`，继续顺排到 `[10]`；范围写作 `[1]–[9]`，不得补零为 `[01]`。
- 左下角只写有依据的数据集、样本量、统计口径、政策或文献出处。没有补充信息就留空。生成器直接使用本页底注字段，禁止以 `note or default_title` 等逻辑回填报告名称。

## 3. 内容决定版式和容器高度

按下表选择主体布局。每相邻两页核查一次卡片的外框位置，再以连续三页为一组滑动检查。禁止相邻卡片坐标完全相同、仅替换文字，也禁止三页连续使用同一种主体布局，包括连续重复“白底细横线加悬空文字”。换主题色、卡片数量或略微移动外框不能代替换一种合适的表达方式。

| 本页要讲的内容 | 主体布局 |
| --- | --- |
| 三个研究维度各有什么做法，本课题从哪里着手 | 实心角标、浅底细虚线卡片、底部通栏切入点 |
| 一个观察如何从原始材料得到 | 左文右图，左右对应到同一张原图、样本或实测记录 |
| 系统如何运行，或工作如何分阶段实施 | 横向流程框图或时间轴，标清输入输出或时间段 |
| 受控实验各组相差多少 | 有效应量和区间时用森林图，比较各组数值时可用柱状图，标明单位 |
| 少量方法、条件或数值需逐行查对 | 三行简洁横线表，列头写清比较口径 |

- 核心算法或建模页必须有关键判据公式，或能读出输入、判断和输出的微型数据流图。数据集划分页必须有划分条块或表格，标清划分名称、单位及已知规模。三行纯文字不能充当这两类页的主体。
- 确定的系统模块、物理协议和原始公文截图用细实线框。方法归类与对比、科学问题、创新点、假设推演、待验证的消融维度与研究切入点，可用左上对齐实心压顶标签、浅灰底和 1 pt 的 DASH 细虚线框。禁用浮夸渐变、发光阴影、Emoji 和路演式超大数字卡片。
- 先定实际文案、换行和段距，再按排出的行高加上下内距设框高。并列卡片需要等高时，取满足最长一列的最小共同高度。问题句紧跟前段，列间可对齐基线，禁止用高框和固定底部锚点拉出中间空层。所有框体、标签与文字保留原生可编辑 Shape/TextFrame，禁止将整块文字贴成图片。

## 4. 按语义使用强调色

并列介绍前人工作时，三个维度、各列的问题句均用中性深蓝灰，仅底部“本课题切入点”用暗红。评价体系或个人成果页只强调确有依据的首要指标或最重要成果，例如第一作者已发表论文。也可让并列项同色，将强调留给收口结论。禁止按位置或索引把第三项、末项机械设为红字或粉底，包括 `if idx == last` 一类写法。

## 5. 图表、案例与个人成果

- 外部论文原图与官方公报截图逐一放大检查四角。校徽、页眉底纹和模板水印均须避开原图、图例、抬头及署名。自绘图已直接标值且省略轴线时，清除悬空的原点字符，如孤立的“0”。有实际数据含义的零值应保留。
- 视频帧与实验样本的图注要说明该处提供的语义线索。例如核对过旁白后可写“43.25 s 旁白点出目标国家”。“14.56 s 语音段中点”只有定位信息。对听不清、看不明的样本，应核对转写或更换例子。
- 个人成果页分清“已发表／已录用成果”和“在审方法储备”。双盲在审稿件只写可公开的方法方向，不透露原题、稿号，也不展示投稿系统后台截图。竞赛奖项按证书字面列出奖项和等级，不贴红章金边奖状扫描件。需要配图时，右侧仅配 1–2 张相关会议口头汇报现场照，图片区的上、下缘分别与左栏对齐。
- 标题默认使用平实的工科学术短语或有依据的实证结论。计入中、英文问号的设问标题全篇最多三页，只用于开场引题、核心问题和结尾呼应，各最多一页。使用“字节构成分析”等可直读的术语，避免“载荷审计”之类生硬直译、四字造词、排比口号和低幼口水标题。计划用“拟比较”“拟测量”等准确动词。正片和底注不印“此处仅为示意”“待预实验确定”“机器排队另建台账”等免责补丁；必要的实验条件写入方法或结果句。

## 6. 交付前强制自检

1. **核对全局大纲。** 从最终 PPTX 的实际放映页序导出文本清单，每页一行，列为“页码、眉题、主标题、底注”。包含封面、过渡页和备查页。读取本页实际显示的文字，包括继承自版式或母版的内容；空字段留空。逐行核对眉题语义与体例、章节编号顺序、标题问号数量和底注。另对全页可见正文、图注和表格检索 `§`、数字引文、补零序号与内部文件名；用本页文献表判断数字引文是否孤立，避免误判备查页。
2. **核对页序依赖。** 增删或调换页面后，复核目录起止页、正片页脚的 `xx / N` 分子与分母，以及逐页讲稿、问答手册中的跳页索引。按实际正片与备查页分界计算 N。
3. **逐页看最终渲染。** 将最终 PPTX 导出为 PDF，再将 PDF 的每一页渲染成独立 PNG。已有输出目录时可用 `pdftoppm -r 144 -png "最终稿.pdf" "核查/页"`。核对 PPTX、PDF、PNG 页数和顺序一致，在可读尺寸逐张审视，并排比较相邻页。检查文本溢出或压线、卡片中部空层、照片擦碰母版底纹、外部图四角、轴线残件和相邻页框体重合。发现问题须回改 PPTX、重新导出并复核受影响页及相邻页。文本清单与逐页目视两项均通过后方可交付。

## 三列研究对照与切入点

使用 [16∶9 可编辑单页](../assets/三列研究对照与切入点.pptx)。在 WPS 中可同时选中三个卡片、四个标签和底栏复制到目标主题，再单独修改标题。按目标母版的页眉和页脚划定正文区。

| 对象 | 位置、尺寸及格式 |
| --- | --- |
| 上部三列 | 三张等宽等高卡片，上下对齐。设正文区总宽为 W，列距 g 约 0.35 in，每列宽为 (W − 2g) / 3。 |
| 压顶标签 | 深色实心直角矩形，贴住内容框上沿，左边对齐。宽为列宽的 55%–65%，高约 0.42 in，白字加粗、水平垂直居中。为保留四边至少 0.15 in 内距，可按字高适当增高。 |
| 卡片内容框 | 直角矩形，填充浅灰蓝 `#F4F6F9`，边框深灰蓝 `#4A6580`、1 pt、标准短划虚线（WPS 的 DASH，对应 DrawingML 的 `dash`）。 |
| 卡片文字 | 加粗小标题“已有研究”下列两行代表性做法，“本研究的处理”下列两行对应做法或约束，再用一行深蓝灰粗体点明具体问题。三列共享紧凑段距和问题句基线，随内容收紧框高。正文行按 14–18 个汉字编排，每行最多 18 字。短标签无需补字。遇到长句先改写，再按语义断行。 |
| 底部通栏 | 左侧实心标签写“本研究的切入点”或“核心结论”，其下紧接同色浅底、同款细虚线框。通栏左边与第一列左边重合，右边与第三列右边重合。框内一行暗红色加粗文字，16–18 pt，直接说清本页的研究切入点或结论。 |

标题、标签、卡片、底栏均使用 WPS 原生可编辑矩形或文本框，带字对象四边各留至少 0.15 in。导出后检查所有正文均为两行、两组之间有明显段距、末行同高、底栏单行。回到选择窗格，确认可以直接改写文字，并单独调整矩形的填充和虚线。
