# 国内高校工科答辩 WPS 版式

## 整套答辩

编排时按每页要讲的内容选择主体布局。下表也用于交付前的幻灯片浏览视图核对。

| 本页要讲的内容 | 主体布局 |
| --- | --- |
| 三个研究维度各有什么做法，本课题从哪里着手 | 实心角标、浅底细虚线卡片、底部通栏切入点 |
| 一个观察如何从原始材料得到 | 左文右图，左右对应到同一张原图、样本或实测记录 |
| 系统如何运行，或工作如何分阶段实施 | 横向流程框图或时间轴，标清输入输出或时间段 |
| 受控实验各组相差多少 | 有效应量和区间时用森林图，比较各组数值时可用柱状图，标明单位 |
| 少量方法、条件或数值需逐行查对 | 三行简洁横线表，列头写清比较口径 |

- **相邻页。** 逐一检查第 1–3、2–4 页等连续三页。任一组三页的主体容器都不能完全相同。换文字、主题色、配图或卡片数量但保留同一种卡片网格，仍算同一布局。根据论证需要调整其中一页。
- **边框。** 已确定的系统模块、物理协议、原始公报截图用细实线框。方法归类与对比、假设推演、待验证的消融维度、问题切入点用 1 pt 细虚线框配浅底色。采用平涂，禁用浮夸渐变、发光阴影、Emoji 和路演式超大数字卡片。
- **标题。** 默认用工科学术短语或有证据支持的实证结论。标题出现“？”或“?”的页面合计最多三页，只可用于开篇引题、核心问题、结尾呼应，各最多一页。
- **文字。** 每行只表达一个动作、条件或观察，沿词组和语义自然断行。去掉排比口号、自造四字词和悬浮长文。计划用“拟比较”“拟测量”等动词，实测结论注明条件。
- **底注。** 仅保留客观的数据集、样本量、政策或文献出处。正片和底注都不放“此处仅为示意”“具体结构待预实验确定”“机器排队另建台账”等制作说明。影响结论的真实限制写进相应方法或结果句。

## 三列研究对照与切入点

使用 [16∶9 可编辑单页](../assets/三列研究对照与切入点.pptx)。在 WPS 中可同时选中三个卡片、四个标签和底栏复制到目标主题，再单独修改标题。按目标母版的页眉和页脚划定正文区。

| 对象 | 位置、尺寸及格式 |
| --- | --- |
| 上部三列 | 三张等宽等高卡片，上下对齐。设正文区总宽为 W，列距 g 约 0.35 in，每列宽为 (W − 2g) / 3。 |
| 压顶标签 | 深色实心直角矩形，贴住内容框上沿，左边对齐。宽为列宽的 55%–65%，高约 0.42 in，白字加粗、水平垂直居中。为保留四边至少 0.15 in 内距，可按字高适当增高。 |
| 卡片内容框 | 直角矩形，填充浅灰蓝 `#F4F6F9`，边框深灰蓝 `#4A6580`、1 pt、标准短划虚线（WPS 的 DASH，对应 DrawingML 的 `dash`）。 |
| 卡片文字 | 从上至下为加粗小标题“已有研究”及两行代表性做法，加粗小标题“本研究的处理”及两行对应做法或约束，最后为一行暗红色加粗的具体问题。三列按相同段距排版，最后一行靠卡片底部并共用基线。正文行按 14–18 个汉字编排，每行最多 18 字。短标签无需补字。遇到长句先改写，再按语义断行。 |
| 底部通栏 | 左侧实心标签写“本研究的切入点”或“核心结论”，其下紧接同色浅底、同款细虚线框。通栏左边与第一列左边重合，右边与第三列右边重合。框内一行暗红色加粗文字，16–18 pt，直接说清本页的研究切入点或结论。 |

标题、标签、卡片、底栏均使用 WPS 原生可编辑矩形或文本框，带字对象四边各留至少 0.15 in。导出后检查所有正文均为两行、两组之间有明显段距、末行同高、底栏单行。回到选择窗格，确认可以直接改写文字，并单独调整矩形的填充和虚线。
